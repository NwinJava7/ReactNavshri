# NAVSHRI

React storefront for Navshri Farms, built with Vite, React, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — typecheck and create a production build in `dist`
- `npm run preview` — preview the production build
- `npm run video:preview` — open the Remotion studio
- `npm run video:render` — render the farm film
